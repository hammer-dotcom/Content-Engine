# Content Engine

A personal content engine built on Claude Skills. It turns a keyword into a publish-ready
first draft in about ten minutes, refreshes articles you've already published, writes in
your own voice, and saves every step to disk so you can fix the one part that broke
instead of starting over.

## What you can do with it

- Take a keyword and get a publish-ready first draft in about ten minutes.
- Refresh and update articles you have already published.
- Make every article sound like you, taught from your own best writing.
- See every step of the work, so you can fix the one part that went wrong instead of
  starting over.

## How it works

Two pipelines, each a chain of small, single-purpose Claude Skills:

- **`/blog-pipeline "keyword"`**: voice-of-customer mining (if you have material) ->
  content gap analysis -> keyword prioritization -> research -> answer-engine audit ->
  your-reference -> outline -> product mentions -> draft -> verify claims -> visuals
  (optional) -> preview.
- **`/update-pipeline "url"`**: extract-content -> update-guidance -> answer-engine audit ->
  update-claims -> update-product-mentions -> update-topic-gaps -> update-draft ->
  update-preview, a full refreshed article with every change marked inline.
- **`/llms-brand-page`**: a site-level, LLM-readable page so ChatGPT, Perplexity, and AI
  Overviews describe your brand accurately.

Every skill reads and writes plain files, nothing is a black box. `CLAUDE.md` has the full
rules the engine follows (the setup gate, data-source toggles, the "average of the
internet" test, writing standards).

## Setup

Install this repo into your Claude Code project, then run:

```
/setup
```

This interviews you (or reads documents you already have: a brand guide, an About page, a
product one-pager) and fills in `your-setup/`:

- `brand-and-voice.md` — who you are, your tone, and a voice profile learned from 5-10 of
  your best articles
- `your-offer.md` — what you sell, for natural, honest product mentions
- `data-sources.md` — which research tools you have connected (all optional, everything
  works with free built-in web search)
- `cms-connection.md` — whether to publish straight to your CMS or hand you a clean
  document

Nothing runs against generic placeholder data. `CLAUDE.md` enforces this with a setup gate
that blocks every content skill until setup is complete.

## Quick start

```
/setup
/blog-pipeline "your target keyword"
```

or, to refresh something you've already published:

```
/update-pipeline "https://yoursite.com/some-article"
```

## Free and cheap tools this engine is built around

- Built-in web search and fetch (always available, no setup)
- Google Search Console MCP (free, your own domain's real ranking and query data)
- DataForSEO MCP (cheap, pay-per-call, no locked-in seat fee)
- A CMS connector matching your platform (WordPress MCP included as the default example)

No dependency on any single paid SEO suite.

## Repo structure

```
CLAUDE.md                  the rules the engine always follows
commands/                  the four slash commands (/setup, /blog-pipeline, /update-pipeline, /llms-brand-page)
skills/                    one folder per skill, each with a SKILL.md
your-setup/                your personalised config, generated by /setup
inputs/voice-of-customer/  drop sales calls, interviews, tickets here (stays local)
content/                   every article's working files, organized by pipeline step
docs/troubleshooting.md    CMS and tool connection steps
```

## Make it yours

Fork it, rename skills, add or remove steps, swap data sources. If you want to change how
a step works, edit its `SKILL.md` directly rather than fighting the pipeline.
